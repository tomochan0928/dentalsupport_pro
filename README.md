# 🦷 DentalSupport Pro

歯科医院のチェアサイドで患者説明に使う、歯列チャート＆治療工程表ツールです。
院内ネットワーク（LAN）内のPC・タブレット（iPad等）のブラウザで動作します。

## 特徴

- **単一HTMLファイル**（`index.html`）で完結。インラインCSS/JSのみ。外部CDN不要。
- 白・水色・グレー基調の清潔感ある医療系レスポンシブUI。
- 上下32本の歯列を表示。各歯は **咬合面(O) / 隣接面(C) / 頬側面(B) / 根尖部(A)** に分割。
- 操作モードで歯をタップして状態を記録。既定モード：
  | モード | 種類 | 挙動 |
  |---|---|---|
  | **う蝕** | 部位指定 | 歯の**部位をクリックして指定**：咬合面=**赤** / 隣接面=**オレンジ** / 頬側面=**黄** |
  | 根尖性歯周炎 (A) | 根尖 | 歯をタップで根元に**赤い病巣マーク** |
  | 欠損（削除） | 欠損 | 歯に**×印**を表示（再タップで解除） |
  | 治療済み(充填/CR) | 着色 | 歯冠全体を**緑**で着色 |
  | 補綴(クラウン/ブリッジ) | 着色 | 歯冠全体を**紫**で着色 |
  | 要観察(CO/初期う蝕) | 着色 | 歯冠全体を**水色**で着色 |
- **う蝕モードは部位をクリックして指定**します。歯のどこをクリックしたかで面が決まります：
  - 中央上下＝**咬合面/頬側面**、左端＝**近心隣接面**、右端＝**遠心隣接面**。
  - **隣接面は近心・遠心が別々**（両面ではなく、クリックした側のみ）に着色されます。
- **操作モードは編集・追加できます**（右パネル「操作モードの編集」）：
  - 全モードの**名称・色を変更**可能（う蝕は咬合面/隣接面/頬側面の3色を個別に変更可）。
  - **「歯全体を着色」タイプの新モードを自由に追加／削除**可能（既定モードは削除不可）。
- 状態に応じて**治療工程と目安回数を自動算出**。複数歯の総治療回数を合計表示。
- 各モード（カテゴリ）ごとに**工程・目安回数・「工程表に連動」のON/OFF**を設定可能（即時反映）。
  連動OFFのモード（例：治療済み・要観察）は総回数に加算されず、「工程表対象外 ×n本」として参考表示されます。
- **医院共通設定**：操作モード・治療工程の設定は患者データとは別に**医院全体の共通設定**として保存され、全患者に適用されます。
- **保存／読込**はローカルサーバーAPI経由。接続不可時は `localStorage` に自動フォールバック。
  - 患者データ（`/api/save`・`/api/load/:patientId`）には**歯の状態のみ**を保存。
  - 医院共通設定（`/api/settings`）にモード・工程設定・医院名を保存。
- **歯列イラストは画像（`tooth-chart.png`）を使用**。リアルな歯の画像の上に半透明の色マークを重ねて表示します。
- **印刷ボタン**で、医院名・患者番号・作成日・歯列図・治療計画・目安回数をまとめた **患者用「治療計画 説明書」** をA4で印刷できます。
- **色マークは歯のシルエットでクリップ**され、歯の輪郭からはみ出しません（`tooth-mask.png` をSVGマスクとして使用）。

## 歯列画像について

- 歯列イラストは**32本の個別の歯画像を合成した** `tooth-chart.png` を表示します（`index.html` と同じフォルダ）。
- 同時に `tooth-mask.png`（白い歯シルエット）を**SVGマスク**として使い、色マークを各歯の内側にクリップします。
- 各歯の座標（中心・幅・上下端）は `index.html` の `TEETH_GEOM` 配列に格納されています。
- 歯列画像を別の個別歯セットに差し替える場合は、同梱の `compose.py` で `tooth-chart.png` / `tooth-mask.png` / `TEETH_GEOM` を再生成してください。

## 印刷（患者用説明書）

左パネルの **「🖨 印刷（患者用）」** を押すとブラウザの印刷画面が開きます。
操作パネル・設定パネルは印刷されず、説明書として必要な情報だけがA4縦で出力されます。
「医院名」を入力しておくと説明書のヘッダーに印字されます。

## 使い方

### ブラウザのみで試す
`index.html` をダブルクリックで開くだけで全機能（描画・工程表）が動作します。
※この場合サーバーAPIが無いため、保存・読込は自動的に `localStorage` にフォールバックします。

### 院内LANでサーバーと連携する（推奨）
Node.js（標準モジュールのみ・追加インストール不要）でローカルサーバーを起動します。

```bash
node server.js
# または
npm start
```

起動後、サーバー機のIPに各端末からアクセス：

```
http://<サーバーPCのIP>:3000
```

- データはサーバーの `./data/<患者番号>.json` に保存されます。
- 外部クラウド・インターネットは一切使用しません。

## API

| メソッド | パス | 説明 |
|---|---|---|
| GET | `/api/health` | 疎通確認 |
| POST | `/api/save` | 患者データ `{ patientId, toothData }` を保存 |
| GET | `/api/load/:patientId` | 患者データを取得（無ければ404→新規扱い） |
| POST | `/api/settings` | 医院共通設定 `{ modes, plan, clinicName }` を保存 |
| GET | `/api/settings` | 医院共通設定を取得（無ければ404→既定を使用） |

## 初期工程表データ

| カテゴリ | 工程 | 目安回数 | 工程表連動 |
|---|---|---|---|
| う蝕 (O/C/B) | 1.う蝕除去 → 2.型取り → 3.セット | 2回 | ON |
| 根尖性歯周炎 (A) | 1.感染根管処置 → 2.根管貼薬(複数回) → 3.根管充填 → 4.支台築造 → 5.窩洞準備・印象 → 6.クラウンセット | 5回 | ON |
| 欠損補綴 | 1.欠損補綴カウンセリング（ブリッジ/インプラント/義歯選定） | 1回 | ON |
| 補綴(クラウン/ブリッジ) | 1.支台形成 → 2.印象 → 3.セット | 3回 | ON |
| 治療済み(充填/CR) | （工程なし） | 0回 | OFF |
| 要観察(CO/初期う蝕) | 1.経過観察・ブラッシング指導 | 1回 | OFF |

いずれも右パネルの「医院共通設定」で変更でき、「💾 医院共通設定を保存」で医院全体に適用されます。
