# 🦷 DentalSupport Pro

歯科医院のチェアサイドで患者説明に使う、歯列チャート＆治療工程表ツールです。
院内ネットワーク（LAN）内のPC・タブレット（iPad等）のブラウザで動作します。

## 特徴

- **単一HTMLファイル**（`index.html`）で完結。インラインCSS/JSのみ。外部CDN不要。
- 白・水色・グレー基調の清潔感ある医療系レスポンシブUI。
- 上下32本の歯列を表示。各歯は **咬合面(O) / 隣接面(C) / 頬側面(B) / 根尖部(A)** に分割。
- 操作モードで歯をタップして状態を記録。既定モード：
  | モード | 種類 | 挙動 |
  |---|---|---|
  | **う蝕** | 部位指定 | 歯の**部位をクリックして指定**：咬合面=**赤** / 隣接面=**オレンジ** / 頬側面=**黄** |
  | 根尖性歯周炎 (A) | 根尖 | 歯をタップで根元に**赤い病巣マーク** |
  | 欠損（削除） | 欠損 | 歯に**×印**を表示（再タップで解除） |
  | 治療済み(充填/CR) | 着色 | 歯冠全体を**緑**で着色 |
  | 補綴(クラウン/ブリッジ) | 着色 | 歯冠全体を**紫**で着色 |
  | 要観察(CO/初期う蝕) | 着色 | 歯冠全体を**水色**で着色 |
- **う蝕モードは部位をクリックして指定**します。歯のどこをクリックしたかで面が決まります：
  - 中央上下＝**咬合面/頬側面**、左端＝**近心隣接面**、右端＝**遠心隣接面**。
  - **隣接面は近心・遠心が別々**（両面ではなく、クリックした側のみ）に着色されます。
- **操作モードは編集・追加できます**（右パネル「操作モードの編集」）：
  - 全モードの**名称・色を変更**可能（う蝕は咬合面/隣接面/頬側面の3色を個別に変更可）。
  - **「歯全体を着色」タイプの新モードを自由に追加／削除**可能（既定モードは削除不可）。
- 状態に応じて**治療工程と目安回数を自動算出**。複数歯の総治療回数を合計表示。
- 各モード（カテゴリ）ごとに**工程・目安回数・「工程表に連動」のON/OFF**を設定可能（即時反映）。
  連動OFFのモード（例：治療済み・要観察）は総回数に加算されず、「工程表対象外 ×n本」として参考表示されます。
- **医院共通設定**：操作モード・治療工程の設定は患者データとは別に**医院全体の共通設定**として保存され、全患者に適用されます。
- **保存／読込**はローカルサーバーAPI経由。接続不可時は `localStorage` に自動フォールバック。
  - 患者データ（`/api/save`・`/api/load/:patientId`）には**歯の状態のみ**を保存。
  - 医院共通設定（`/api/settings`）にモード・工程設定・医院名を保存。
- **歯列イラストは画像（`tooth-chart.png`）を使用**。リアルな歯の画像の上に半透明の色マークを重ねて表示します。
- **印刷ボタン**で、医院名・患者番号・作成日・歯列図・治療計画・目安回数をまとめた **患者用「治療計画 説明書」** をA4で印刷できます。
- **色マークは歯のシルエットでクリップ**され、歯の輪郭からはみ出しません（`tooth-mask.png` をSVGマスクとして使用）。

## 歯列画像について

- 歯列イラスト（`tooth-chart.png`）とシルエットマスク（`tooth-mask.png`）は **`index.html` 内に data URI として埋め込み済み**です。
  そのため **`index.html` 単体をダブルクリックで開くだけ**で歯列表が表示されます（画像ファイルを同じ場所に置く必要はありません）。
- 歯列イラストは**32本の個別の歯画像を合成**したもの。`tooth-mask.png`（白い歯シルエット）を**SVGマスク**として使い、各歯のbboxクリップと併用して、色マークを各歯の内側にクリップ（隣の歯にはみ出しません）。
- **歯式番号は Palmer 表記（各象限 1〜8）**を焼き込み済み。中央線と R/L（R=患者右=画面左）で象限を表示。
- 上下とも**患者の右を画面左**にそろえた標準チャート配置です。
- リポジトリ内の `tooth-chart.png` / `tooth-mask.png` は再生成・参照用で、表示には不要です。
- 各歯の座標（中心・幅・上下端）は `index.html` の `TEETH_GEOM` 配列に格納されています。
- 歯列画像を別の個別歯セットに差し替える場合は、同梱の `compose.py` で `tooth-chart.png` / `tooth-mask.png` / `TEETH_GEOM` を再生成してください。

## 印刷（患者用説明書）

左パネルの **「🖨 印刷（患者用）」** を押すとブラウザの印刷画面が開きます。
操作パネル・設定パネルは印刷されず、説明書として必要な情報だけがA4縦で出力されます。
「医院名」を入力しておくと説明書のヘッダーに印字されます。

## インストール・起動（サーバーPC）

院内のサーバー役にするPCに導入します。患者データはこのPCの `data/` フォルダに保存され、院内の各端末（PC・iPad）からブラウザでアクセスします。**外部クラウド・インターネットは一切使用しません。**

### 方法A：実行ファイル版（推奨・Node.js不要・一番かんたん）

1. `dist/DentalSupportPro.exe`（Windows用・約32MB／**Windows 7 以降対応**）を、データを置きたいフォルダ（例：デスクトップに「DentalSupport」フォルダを作る）に入れる。
2. **ダブルクリックで起動**。黒いウィンドウが開き、**自動でブラウザが立ち上がります**。
3. ウィンドウに表示される **院内の他端末用URL（例：`http://192.168.x.x:3000`）** を、iPad等のブラウザのお気に入りに登録すれば、同じLAN内のどの端末からも使えます。
4. 終了する時は黒いウィンドウを閉じます（開いている間だけ動作）。
   - 患者データ・医院共通設定は、exe と同じ場所に作られる **`data/` フォルダ**に保存されます（バックアップはこのフォルダをコピー）。
   - Node.js のインストールは不要です。

> Mac の場合は実行ファイル `DentalSupportPro-mac` を `npm run build:mac` で作成できます。

### 方法B：Node.js ＋ 起動スクリプト

Node.js（https://nodejs.org/ja）をインストール後、`start-windows.bat`（Mac は `start-mac.command`）を**ダブルクリック**。または：

```bash
node server.js   # または npm start
```

起動後、表示されるURL（`http://localhost:3000` ／ 院内LANは `http://<サーバーPCのIP>:3000`）にアクセス。

### 実行ファイルを自分でビルドする

```bash
npm install
npm run build:win   # dist/DentalSupportPro.exe を生成（Windows 7対応 Node14ビルド）
# npm run build:all  # win / mac / linux をまとめて生成
# npm run build:dist # exeビルド＋配布zip(文字コード調整済)を生成
```

### スタートアップ自動起動（PC起動時に自動でサーバーを立ち上げる・Windows）

毎朝の手動起動が不要になります。**サーバー役のPC**で、`DentalSupportPro.exe` と以下のスクリプトを同じフォルダに置いてから操作します。

| 操作 | ファイル |
|---|---|
| **自動起動を登録**（ログオン時に自動起動） | `autostart-install.vbs` をダブルクリック |
| 自動起動を解除 | `autostart-uninstall.vbs` をダブルクリック |
| 今すぐ静かに起動（画面に出さず・ブラウザも開かない） | `start-hidden.vbs` |
| サーバーを停止 | `stop-server.bat` |
| このPCでアプリを開く | `open-app.bat`（または `http://localhost:3000`） |

- 自動起動はバックグラウンド（ウィンドウ非表示）で動くため、サーバーPCの画面はすっきりしたままです。
- 各端末（iPad等）は、表示される **`http://（サーバーPCのIP）:3000`** にアクセスします（IP固定を推奨）。
- 仕組み：`autostart-install.vbs` が Windows のスタートアップフォルダに `start-hidden.vbs`（exeを非表示・`NO_OPEN=1`で起動）へのショートカットを作成します。レジストリは変更しません。

> Mac は「システム設定 → 一般 → ログイン項目」に `DentalSupportPro-mac` を追加すると同様に自動起動できます。

### 子パソコン（受付・診療室の端末）の導入

子パソコンは**サーバーに接続して使うだけ**なので、特別なソフトは不要です。配布物の `DentalSupportPro-Client`（`client-install.vbs` ほか）を使います。

**Windows端末：**
1. `client-install.vbs` をダブルクリック
2. サーバーPCのIPアドレスを入力（例 `192.168.1.50`）→ OK
3. デスクトップに **「DentalSupport Pro」アイコン**が作成され、ダブルクリックでアプリが開きます
   - Edge / Chrome があれば **アプリ専用ウィンドウ**（タブ・アドレスバー無し）で開きます
   - アイコン削除は `client-uninstall.vbs`、IP変更は再度 `client-install.vbs`

**iPad / iPhone：**
Safari で `http://（サーバーIP）:3000` を開き、「共有」→「ホーム画面に追加」。アプリのように使えます。

### サーバーを使わずブラウザだけで試す
`index.html` をダブルクリックで開くだけでも全機能が動作します（この場合サーバーAPIが無いため、保存・読込は自動的にその端末の `localStorage` にフォールバックします）。

## API

| メソッド | パス | 説明 |
|---|---|---|
| GET | `/api/health` | 疎通確認 |
| POST | `/api/save` | 患者データ `{ patientId, toothData }` を保存 |
| GET | `/api/load/:patientId` | 患者データを取得（無ければ404→新規扱い） |
| POST | `/api/settings` | 医院共通設定 `{ modes, plan, clinicName }` を保存 |
| GET | `/api/settings` | 医院共通設定を取得（無ければ404→既定を使用） |

## 初期工程表データ

| カテゴリ | 工程 | 目安回数 | 工程表連動 |
|---|---|---|---|
| う蝕 (O/C/B) | 1.う蝕除去 → 2.型取り → 3.セット | 2回 | ON |
| 根尖性歯周炎 (A) | 1.感染根管処置 → 2.根管貼薬(複数回) → 3.根管充填 → 4.支台築造 → 5.窩洞準備・印象 → 6.クラウンセット | 5回 | ON |
| 欠損補綴 | 1.欠損補綴カウンセリング（ブリッジ/インプラント/義歯選定） | 1回 | ON |
| 補綴(クラウン/ブリッジ) | 1.支台形成 → 2.印象 → 3.セット | 3回 | ON |
| 治療済み(充填/CR) | （工程なし） | 0回 | OFF |
| 要観察(CO/初期う蝕) | 1.経過観察・ブラッシング指導 | 1回 | OFF |

いずれも右パネルの「医院共通設定」で変更でき、「💾 医院共通設定を保存」で医院全体に適用されます。
