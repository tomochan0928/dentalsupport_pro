# 🦷 DentalSupport Pro

歯科医院のチェアサイドで患者説明に使う、歯列チャート＆治療工程表ツールです。
院内ネットワーク（LAN）内のPC・タブレット（iPad等）のブラウザで動作します。

## 特徴

- **単一HTMLファイル**（`index.html`）で完結。インラインCSS/JSのみ。外部CDN不要。
- 白・水色・グレー基調の清潔感ある医療系レスポンシブUI。
- 上下32本の歯列を表示。各歯は **咬合面(O) / 隣接面(C) / 頬側面(B) / 根尖部(A)** に分割。
- 操作モードで歯をタップして状態を記録。既定モード：
  | モード | 種類 | 挙動 |
  |---|---|---|
  | 咬合面 (O) | 部位 | 咬合面を**赤**に染色 |
  | 隣接面 (C) | 部位 | 隣接面（側面）を**オレンジ**に染色 |
  | 頬側面 (B) | 部位 | 頬側面（表面）を**黄**に染色 |
  | 根尖性歯周炎 (A) | 部位 | 根元に**赤い病巣マーク**を表示 |
  | 欠損（削除） | 欠損 | 歯に**×印**を表示（再タップで解除） |
  | 治療済み(充填/CR) | 着色 | 歯冠全体を**緑**で着色 |
  | 補綴(クラウン/ブリッジ) | 着色 | 歯冠全体を**紫**で着色 |
  | 要観察(CO/初期う蝕) | 着色 | 歯冠全体を**水色**で着色 |
- **操作モードは編集・追加できます**（右パネル「操作モードの編集」）：
  - 全モードの**名称・色を変更**可能。
  - **「歯全体を着色」タイプの新モードを自由に追加／削除**可能（既定5モードは削除不可）。
- 状態に応じて**治療工程と目安回数を自動算出**。複数歯の総治療回数を合計表示。
- 各モード（カテゴリ）ごとに**工程・目安回数・「工程表に連動」のON/OFF**を設定可能（即時反映）。
  連動OFFのモード（例：治療済み・要観察）は総回数に加算されず、「工程表対象外 ×n本」として参考表示されます。
- **保存／読込**はローカルサーバーAPI経由。接続不可時は `localStorage` に自動フォールバック。
- **歯列イラストは画像（`tooth-chart.png`）を使用**。リアルな歯の画像の上に半透明の色マークを重ねて表示します。
- **印刷ボタン**で、医院名・患者番号・作成日・歯列図・治療計画・目安回数をまとめた **患者用「治療計画 説明書」** をA4で印刷できます。

## 歯列画像について

- 歯列イラストは同梱の `tooth-chart.png`（`index.html` と同じフォルダ）を読み込んで表示します。
- マークの位置は、この `tooth-chart.png` を**画像解析して検出した各歯の中心位置**に合わせて精密に較正済みです
  （`index.html` 内の `TOOTH_CX`：各歯中心の横位置、`GEOF`：根尖/咬合面などの縦位置）。
- 歯列画像を別のものに差し替える場合は、`tooth-chart.png` を置き換えたうえで `TOOTH_CX` / `GEOF` の値を調整してください。

## 印刷（患者用説明書）

左パネルの **「🖨 印刷（患者用）」** を押すとブラウザの印刷画面が開きます。
操作パネル・設定パネルは印刷されず、説明書として必要な情報だけがA4縦で出力されます。
「医院名」を入力しておくと説明書のヘッダーに印字されます。

## 使い方

### ブラウザのみで試す
`index.html` をダブルクリックで開くだけで全機能（描画・工程表）が動作します。
※この場合サーバーAPIが無いため、保存・読込は自動的に `localStorage` にフォールバックします。

### 院内LANでサーバーと連携する（推奨）
Node.js（標準モジュールのみ・追加インストール不要）でローカルサーバーを起動します。

```bash
node server.js
# または
npm start
```

起動後、サーバー機のIPに各端末からアクセス：

```
http://<サーバーPCのIP>:3000
```

- データはサーバーの `./data/<患者番号>.json` に保存されます。
- 外部クラウド・インターネットは一切使用しません。

## API

| メソッド | パス | 説明 |
|---|---|---|
| GET | `/api/health` | 疎通確認 |
| POST | `/api/save` | `{ patientId, toothData, settings }` を保存 |
| GET | `/api/load/:patientId` | 患者データを取得（無ければ404→新規扱い） |

## 初期工程表データ

| 疾患 | 工程 | 目安回数 |
|---|---|---|
| 虫歯 (O/C/B) | 1.う蝕除去 → 2.型取り → 3.セット | 2回 |
| 根尖性歯周炎 (A) | 1.感染根管処置 → 2.根管貼薬(複数回) → 3.根管充填 → 4.支台築造 → 5.窩洞準備・印象 → 6.クラウンセット | 5回 |
| 欠損 | 1.欠損補綴カウンセリング（ブリッジ/インプラント/義歯選定） | 1回 |

いずれも右パネルの設定で変更でき、変更は現在の患者の工程表計算へ即時反映されます。
