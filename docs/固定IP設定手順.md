# サーバーPCの IPアドレス固定 手順書

DentalSupport Pro は、サーバー役のPCのIPアドレス（例：`192.168.1.50`）に各端末（iPad等）からアクセスします。
このIPは**何もしないとPC再起動時に変わることがあり**、変わるとブックマークでつながらなくなります。
そこで **IPアドレスを固定** します。

方法は2つ。**どちらか一方**でOKです。

- **方法A：ルーターでDHCP予約（おすすめ・PC側の設定変更なし）**
- 方法B：Windows側で固定IPを設定

---

## 0. まず現在の情報を調べる（共通）

サーバー役のPCで行います。

1. キーボードの **Windowsキー** を押し、`cmd` と入力して **コマンドプロンプト** を開く
2. 次を入力して Enter：

   ```
   ipconfig /all
   ```

3. 「**イーサネット アダプター**」または「**Wi-Fi**」の欄から、以下をメモします：

   | 項目 | 表示例 | メモ |
   |---|---|---|
   | IPv4 アドレス | `192.168.1.50` | 現在のIP |
   | サブネット マスク | `255.255.255.0` |  |
   | デフォルト ゲートウェイ | `192.168.1.1` | ルーターのIP |
   | 物理アドレス（MACアドレス） | `AB-CD-EF-12-34-56` | 方法Aで使用 |
   | DNS サーバー | `192.168.1.1` など |  |

> 💡 サーバーPCは**有線LAN（イーサネット）接続**がおすすめです（安定します）。

---

## 方法A：ルーターでDHCP予約（推奨）

「このPC（MACアドレス）には、いつも同じIPを渡す」設定をルーター側で行います。PC側の設定は変えません。

1. ブラウザでルーターの管理画面を開く
   - アドレス欄に **デフォルトゲートウェイのIP**（例 `192.168.1.1`）を入力
   - ルーターのユーザー名／パスワードでログイン（本体の側面ラベルや説明書に記載）
2. メニューから次のような項目を探す（メーカーで名称が違います）：
   - 「**DHCP予約**」「**固定IP割り当て**」「**IPアドレス予約**」「**Static DHCP**」「**アドレス予約**」など
3. 「追加」して、次を登録：
   - **MACアドレス**：0でメモした値（区切りは `-` か `:`）
   - **IPアドレス**：固定したいIP（**現在のIPのままでOK**、例 `192.168.1.50`）
4. 保存 → ルーターを再起動（または設定反映）
5. サーバーPCを再起動し、`ipconfig` でIPが同じことを確認

✅ これで、PCを再起動してもIPは変わりません。

---

## 方法B：Windowsで固定IPを設定

ルーターを触れない場合はこちら。**ゲートウェイ／サブネット／DNSを間違えるとネットにつながらなくなる**ので、0でメモした値を正確に入れてください。

1. **Windowsキー** → `ncpa.cpl` と入力して Enter（「ネットワーク接続」が開く）
2. 使用中の接続（**イーサネット** または **Wi-Fi**）を右クリック → **プロパティ**
3. 「**インターネット プロトコル バージョン 4 (TCP/IPv4)**」を選び → **プロパティ**
4. 「**次のIPアドレスを使う**」を選び、入力：
   - **IPアドレス**：固定したいIP（例 `192.168.1.50`）
     - ※ ルーターのDHCP配布範囲外の番号が安全（例：範囲が `.100〜.200` なら `.50` を使う）
   - **サブネット マスク**：0のメモ（例 `255.255.255.0`）
   - **デフォルト ゲートウェイ**：0のメモ（例 `192.168.1.1`）
5. 「**次のDNSサーバーのアドレスを使う**」を選び：
   - **優先DNS**：ゲートウェイと同じ（例 `192.168.1.1`）でOK
6. **OK** → 閉じる
7. `ipconfig` で設定どおりになっていること、ブラウザでインターネットが見られることを確認

> 元に戻すときは手順4・5で「**IPアドレスを自動的に取得する**」「**DNSサーバーのアドレスを自動的に取得する**」に戻します。

---

## 仕上げ：つながるか確認

1. サーバーPCで DentalSupport Pro を起動（exe または自動起動）
2. **別の端末（iPad等）**のブラウザで
   ```
   http://（固定したIP）:3000
   例) http://192.168.1.50:3000
   ```
   にアクセスし、歯列チャートが表示されればOK
3. そのURLを各端末の**ホーム画面／お気に入りに登録**

---

## うまくいかない時

- **他端末から開けない**
  - サーバーPCで一度 `open-app.bat`（または `http://localhost:3000`）が開くか確認
  - サーバーPCと端末が**同じWi-Fi/LAN**につながっているか
  - **Windows ファイアウォール**で初回にブロックされたら、**「アクセスを許可する」**を選ぶ（プライベートネットワークにチェック）
- **IPが思った値にならない**
  - 方法Aは MACアドレスの入力ミスがないか確認
  - 方法Bは「自動的に取得」に戻っていないか確認
- **ポート3000が使用中と出る**
  - すでに起動済みの可能性。`stop-server.bat` で停止してから起動
