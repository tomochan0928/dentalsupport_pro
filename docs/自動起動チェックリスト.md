# 自動起動 動作確認チェックリスト

サーバー役のPCで、上から順にチェック（☐→☑）してください。
所要時間：約10分。

## 事前準備

- ☐ `DentalSupportPro.exe` と各スクリプト（`autostart-install.vbs` 等）が **同じフォルダ**にある
- ☐ そのフォルダを**最終的に置く場所**（例：`C:\DentalSupport`）に移動済み
      （登録後にフォルダを移動すると自動起動のリンク先がずれます）
- ☐ サーバーPCのIPアドレスを**固定済み**（別紙「固定IP設定手順」）　→ 固定IP：`______________`

## 1. 手動で起動できるか

- ☐ `DentalSupportPro.exe` をダブルクリック
- ☐ 黒いウィンドウに「DentalSupport Pro サーバーを起動しました」が出る
- ☐ ブラウザが自動で開き、歯列チャートが表示される
- ☐ 黒いウィンドウに表示された **院内の他端末用URL** をメモ：`http://__________:3000`
- ☐ 確認できたら、黒いウィンドウを**閉じて**いったん終了

## 2. 自動起動を登録

- ☐ `autostart-install.vbs` をダブルクリック
- ☐ 「自動起動を登録しました」のメッセージが出る → **OK**
- ☐ （任意）登録を目視確認：Windowsキー→`shell:startup`→Enter で開くフォルダに
      **「DentalSupport Pro」**というショートカットがある

## 3. 再起動して自動で立ち上がるか（本番確認）

- ☐ PCを**再起動**（またはサインアウト→サインイン）
- ☐ ログオン後、**1分ほど待つ**（画面には何も出ません＝正常）
- ☐ タスクマネージャーで確認：
      `Ctrl + Shift + Esc` → 「詳細」タブ →
      一覧に **`DentalSupportPro.exe`** がある（＝サーバー稼働中）
- ☐ このPCで `open-app.bat` をダブルクリック → ブラウザでチャートが開く
      （または `http://localhost:3000`）

## 4. 院内の他端末から使えるか

- ☐ iPad等で `http://（固定IP）:3000` を開く → チャートが表示される
- ☐ そのURLを端末の**ホーム画面/お気に入り**に登録

## 5. データ保存・共有の確認

- ☐ 端末Aで患者番号を入力 → 何本か歯にマーク → **「💾 保存」**
- ☐ 端末B（または別ブラウザ）で同じ患者番号 → **「📥 読込」** → 同じ内容が出る
- ☐ サーバーPCのフォルダ内 **`data`** フォルダに `（患者番号）.json` ができている
- ☐ 「⚙️ 医院共通設定」で医院名やモードを変更 →「💾 医院共通設定を保存」→
      別端末を再読込しても設定が反映される（`data\_clinic.json` が作られる）

## 6. 停止・解除の確認（運用テスト）

- ☐ `stop-server.bat` をダブルクリック → タスクマネージャーから `DentalSupportPro.exe` が消える
- ☐ もう一度 `start-hidden.vbs` で静かに起動できる
- ☐ （自動起動をやめる場合のみ）`autostart-uninstall.vbs` → スタートアップのショートカットが消える

---

## 合格基準

**3・4・5 がすべて☑** なら、毎朝PCを起動するだけで全端末から使える状態です。

---

## つまずいたら

| 症状 | 対処 |
|---|---|
| 再起動後 `DentalSupportPro.exe` が動いていない | フォルダを移動していないか確認。`autostart-uninstall.vbs`→`autostart-install.vbs` で再登録 |
| 他端末から開けない | 同じLANか／ファイアウォールで「アクセスを許可」したか／IPが固定値か |
| 「ポート3000は使用中」 | 二重起動。`stop-server.bat` で停止してから起動 |
| ブラウザに古い画面が出る | ブラウザを再読込（更新）／キャッシュ削除 |
| データが共有されない | 各端末が**サーバー経由**（`http://IP:3000`）で開いているか確認（`index.html`直開きは端末内保存になります） |
