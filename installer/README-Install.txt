DentalSupport Pro  サーバーPC（インストール版）
=========================================================

■ インストール先
  C:\DentalSupportPro（変更した場合はその場所）
    DentalSupportPro.exe … サーバー本体
    index.html           … 画面（画面右上「設定」→アプリの更新 で差し替わります）
    data\                … 患者データ・医院共通設定・説明写真（バックアップ対象）

■ 毎日の使い方
  ・PCの電源を入れてログオンすると、サーバーが自動で（画面に出ずに）起動します。
    （インストール時に「自動起動」を選んだ場合）
  ・このPCで使う   … デスクトップの「DentalSupport Pro」をダブルクリック
                      （サーバーが止まっていれば自動で起動してから開きます）
  ・iPad／子パソコン … スタートメニュー「DentalSupport Pro」→「接続先アドレスを確認」
                      で表示される http://（このPCのIP）:3000 を開く

■ スタートメニュー「DentalSupport Pro」
  DentalSupport Pro を開く     … アプリを開く（必要ならサーバーを起動）
  接続先アドレスを確認         … 他端末用のアドレスとサーバーの状態を表示
  サーバーを起動（画面なし）   … サーバーだけを起動
  サーバーを停止               … サーバーを止める
  インストール先フォルダを開く … data フォルダのバックアップなどに
  クイックガイド／固定IP設定手順
  アンインストール

■ バックアップ
  C:\DentalSupportPro\data フォルダを丸ごとUSBメモリ等にコピーしてください。
  （患者データ・医院共通設定・説明写真がすべて入っています）

■ バージョンアップ
  ・画面だけの更新 … アプリの画面右上の「設定」→「アプリの更新」で index.html を選ぶ
  ・全体の更新     … 新しい DentalSupportPro-Setup.exe を実行（上書きインストール）
                      data フォルダ（患者データ）はそのまま残ります。

■ 以前の「zip版」から移行する場合
  1. zip版のフォルダの data フォルダを、C:\DentalSupportPro\data に上書きコピー
  2. スタートメニュー「サーバーを停止」→「DentalSupport Pro を開く」
  ※ zip版の自動起動登録は、インストール時に自動で解除されます。

■ アンインストール
  コントロールパネル「プログラムと機能」→「DentalSupport Pro」
  または スタートメニュー「アンインストール」。
  患者データ（data フォルダ）を残すかどうかは途中で確認されます（既定は「残す」）。

※ インターネット・クラウドは使いません（院内LANのみ）。
